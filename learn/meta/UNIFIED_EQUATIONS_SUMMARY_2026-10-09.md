# 统一方程、我们的近似、实际误差，以及精度要求能否放低（2026-10-09）

依据：`HULL_FORCE_INDEPENDENT_REDERIVATION_2026-10-09.md`（统一方程）、`HULL_FORCE_DERIVATION_2026-10-09.md`（降阶与误差阶）、`HULL_FORCE_AUDIT_REVIEW_2026-10-09.md`（检验 V1–V6、S1–S4）、`ACCEPTANCE_2026-10-06.md`（验收要求）。每条结论标明来源；标签：**[精确]** 构造上精确、**[推导]** 由方程推出并有数值确认、**[假设]** 登记的经验项、**[未知]** 没有参考解。

## 1. 统一方程（精确问题）

### 1.1 流体与边界条件

水不可压、外部流动无旋，速度势 Φ(x, t)：

$$\nabla^2\Phi = 0 \quad \text{在流域 } \Omega(t)\text{ 内。}$$

船体湿表面 S_w(t) 上不穿透：

$$\partial_n\Phi = \mathbf V_B\cdot\mathbf n,\qquad \mathbf V_B = \mathbf U + \boldsymbol\omega\times\mathbf r .$$

自由面 z = η(x, y, t) 上两个条件（完全非线性）：

$$\eta_t + \nabla_H\Phi\cdot\nabla_H\eta = \Phi_z,\qquad
\Phi_t + \tfrac12|\nabla\Phi|^2 + g\eta = 0 .$$

远场辐射条件；入射波 Φ_I 给定（线性深水波，这是输入的限定，不是方程的限定）。

把自由面上的势记为 ψ(x, y, t) = Φ(x, y, η, t)，法向通量 W = Φ_z − ∇η·∇_HΦ，就得到只在自由面上演化的形式（Zakharov–Craig–Sulem）：

$$\eta_t = W,\qquad
\psi_t = -g\eta - \tfrac12|\nabla\psi|^2 + \frac{(W + \nabla\eta\cdot\nabla\psi)^2}{2(1+|\nabla\eta|^2)},$$

其中 W 由 Dirichlet–Neumann 算子给出：对固定的瞬时几何，拉普拉斯问题是线性的，所以

$$W = \mathcal G(q,\eta,\chi)\,\psi + \mathcal B(q,\eta,\chi)\,\nu + w_{\rm in} .$$

q 是船体位姿，ν 是六维速度，χ 是分离/尾流状态。**航速 U 只通过 V_B 和基流进入，没有任何按航速的分支**——这就是"一套方程"的含义（验收规则 G1）。

### 1.2 压力、力、运动

$$p = -\rho\left(\Phi_t + \tfrac12|\nabla\Phi|^2 + gz\right),\qquad
\mathbf F = -\int_{S_w} p\,\mathbf N\,dS + \mathbf F_{\rm visc},$$

$$[M_{RB} + M_a(q,\eta,\chi)]\,\dot\nu = \mathbf F_{\rm other} - C_{RB}(\nu)\nu + \mathbf f_{\rm fluid}(q,\nu,\eta,\psi,\chi).$$

与刚体加速度成正比的压力（附加质量）必须放在左边联立，强入水时不能当外力显式加（原文 §3.5：减速项与动量项同量级）。

### 1.3 势流推不出、必须作闭合的部分 [假设]

1. **分离与通气**：折角线和船尾处流动何时脱离、脱离后腔内压力是否为大气压（取决于空气通路）。势流只给出"若分离则 p = p_atm 于自由流线"，不给出是否分离。
2. **飞溅切除**：薄射流携带动量、几乎不受力，在离开船体处切掉。
3. **黏性**：边界层薄（δ/L 约 1%），只贡献壁面切应力，用摩擦线（ITTC-57）；对压力的影响 O(δ/b) 可忽略。
4. **横倾超过斜升角、再入自身尾流**：无成熟理论。

这些不是近似误差，是模型边界；它们在任何求解精度下都存在。

## 2. 我们实际算的近似（D1′）及其推导

### 2.1 精确拆分 [精确]

令 S_g 为船体在**入射波面**以下的部分（由 q 和 η_I 闭式可知），

$$\mathbf F = \mathbf F_{HF}(S_g) + \mathbf F_{\rm dist} + \mathbf F_{\rm visc},\qquad
\mathbf F_{HF} = -\rho\int_{S_g}\left(gz + \Phi_{I,t} + \tfrac12|\nabla\Phi_I|^2\right)\mathbf N\,dS .$$

F_HF 按多边形截面闭式积分，48 站位的离散误差 2.7×10⁻³（原文 §4.1）。F_dist 收下其余一切（扰动势、堆高、喷根、船尾凹陷、真实湿面与 S_g 的差）。这一步没有近似，只是定义。

### 2.2 组合近似 [推导]

把运动与波浪的幅度记为 δ，把"完整三维带重力问题"记为 p，"切片模型"记为 0。精确响应展开 F(δ;p) = Σ_m a_m(p)δ^m/m!。组合模型取

$$\mathbf F_c = \underbrace{a_0(p) + a_1(p)\,\delta}_{\text{精确三维线性解 }F^{3D,\rm lin}}
+ \underbrace{\sum_{m\ge2} a_m(0)\frac{\delta^m}{m!}}_{\text{切片非线性增量 }\sum[f^{NL}-f^{\rm lin}]\Delta x},$$

写成实现形式

$$\mathbf F = \mathbf F_{HF}(S_g) + \sum_{\text{截面}} f^{NL}\Delta x + \big[\mathbf F^{3D,\rm lin} - \sum f^{\rm lin}\Delta x\big] + \mathbf F_{\rm visc}.$$

**精确的条件**：f^lin 必须是所用 f^NL 的精确线性化（否则留下 O(δ) 的重复计算）。检验 V1 证明：取数值雅可比时，静止和 5 节、迎浪和顺浪，组合与纯三维线性解相差 ≤0.9%（2 毫米幅度到小数后三位相同）。

**误差**：

$$\mathbf F - \mathbf F_c = \sum_{m\ge2}\big[a_m(p) - a_m(0)\big]\frac{\delta^m}{m!},$$

首项是三维问题的二阶响应与切片二阶响应之差。（2026-10-09 更正：不是 δ 与 p 的混合导数。）

### 2.3 三维线性解 F^{3D,lin} [精确/推导，工具受限]

- 静止：三维面元法（Capytaine 与仓库 Rankine 互相验证到 1–3%），辐射记忆用 Cummins 形式

$$\mathbf F_{\rm rad}(t) = -A_\infty\dot\nu - \int_0^t K(t-s)\,\nu(s)\,ds,\qquad K(t)=\frac2\pi\int_0^\infty B(\omega)\cos\omega t\,d\omega,$$

状态空间拟合（S3：频域矢量拟合，外部给定 A_∞，被动性强制）。
- 航速：同一方程围绕双体基流线性化（B6）。**航速只通过基流进入，不能有"记忆开关"**（G1 复核已把"仅 τ_B<1/4 开启"改为始终开启，记忆核在高速自然变短）。
- 滑行航速：目前只有无重力的升力面核（线性细长翼理论的三维修正，V3 验证了它对纵倾的预测）。带重力的三维线性滑行解（B7）自身平衡姿态偏低 0.3–1.7°。

### 2.4 切片（2D+t）截面模型 [推导+假设]

细长体约化：在随船以 U 向后输运的横截面平面内解二维入水问题。
- 推导出的误差阶（原文 §3.2，升力面精确计算确认）：内部 O(ε²)，ε = b/L_w；船尾与压力中心 O(ε)。对本船：升力误差 2–8%（折角线在船尾前浸湿）或 13–17%（35–40 节折角线在船尾仍干）；压力中心 0.03–0.13 个船宽。这些就是 2.3 里三维修正表要补的量。
- 入水（折角线干）：修正 Logvinovich，对等速相似解 −1.7/+2.1/+9.1%（10/20/30°）[推导]；楔形截面非线性对升力系数的修正是闭式常量 −(1−0.733)·π/4·tanτ（V4 全部工况吻合）。
- 浸湿后 [假设]：系数 C = f/(ρcV²)。V5：冻结规则（0）被试验排除；稳定值接近无重力稳态值的 0.7–1.0 倍；到达稳态比 Wen 公式快得多；在截面傅汝德数 0.28–0.55 看不出重力影响。极限分析（审计复核 §2.1）表明低速极限是水面合拢、不是系数趋零，且在稳态滑行里该力依赖三维通气——**没有二维推导能给出它**。
- 出水 [假设]：不计动量释放，弱验证。

### 2.5 冲击的时间分辩 [推导]

入水时长 2–12 个 0.02 秒步；半正弦脉冲采样损失 3–19%。V6：不滤波时峰值均值随步长变 4–20%、极值变 20–40%；规定 20 赫兹（全尺度）二阶低通后，均值在全尺度 0.01 秒步长内收敛到 2%，极值要 0.005 秒。**不定义滤波，加速度统计就是积分器的属性。**

**三个真正的难点**（不是努力就能消掉的）：
1. 滑行段没有三维非线性参考解（文献里的"可数值求解"只在排水型船得到验证；见审计复核的三层区分）。
2. 工作幅度下静止/低速的三维动力非线性不能展开（S4），也没有预算内的求解路线。
3. 6–14 节没有小参数、没有工具。

## 4. 精度要求能否放低

### 4.1 现在的要求（验收文档 A1–A7）与达成情况

| 项 | 要求 | 现状 |
|---|---|---|
| A1 静水阻力 | ±10% | 16–25 节 ±3–6%；30–40 节 −6…−15%（摩擦与湿面积；Savitsky 在 40 节自身无效） |
| A2 纵倾 | ±0.5° | 16–40 节 ≤0.35°（V3 修正后） |
| A3 波浪运动 | ±20% | 静止小幅成立；航速下未用 D1′ 测；旧船模短波多算 1.3–1.5 倍 |
| A4 加速度统计 | ±30%，带滤波 | 滤波已定义；旧船模 1971 为实测的 0.61–0.81；数据本身 ±40% |
| A5 截面冲击 | ±10% 对二维非线性解 | 折角线干时成立；浸湿后 0.7–0.9 倍 Wen 稳态（约 ±30%） |

| A7 横向 | 一致性 | 未覆盖 |
| 6–14 节 | （隐含全速度） | 未覆盖 |

### 4.2 放低哪些、不放低哪些（从控制的目的推）

控制器需要的是：在任意航速下稳定；对波浪的平均效应和加速度统计有正确的量级与趋势；误差模型会在线学掉静态偏差（已有结论：在线学习的收益主要是静态重标定）。由此：

**可以放低的（绝对精度）**
1. **滑行段的验证标准**：从"相对精确解有界"改为"在试验散布之内"（Savitsky ±10%，Fridsma 的转录与周期不确定）。现在 A1、A2 已经接近达成；再往下追，追的是数据本身的噪声。
2. **浸湿后系数、船尾通气、摩擦与飞溅面积**：登记为带区间的经验项（例如浸湿后系数取 Wen 稳态值的 0.5–1.0 倍），**在仿真中随机化**，而不是追求单一精确值。验收文档对通气已允许"登记、随机化"；这与误差模型要学习的对象一致——控制器对这些区间要稳健，本来就是研究目的。
3. **工作幅度下静止/低速的三维动力非线性**：标为"静水与入射波部分精确、动力部分线性加截面阈值非线性、误差未知"。这一状态（静止、四级海况、短波）不是控制器的工作点，可以明确排除出验收范围或只要求定性正确。
4. **6–14 节**：改为"两端极限之间、无开关、无加权，误差未知并随机化"；要求的是**连续性与无伪动力学**（没有漂移、没有伪极限环、平衡唯一或分支被登记），不是百分比。

**不能放低的（结构正确性）**
1. **一套方程、不按航速拼接**（G1）：这是放低绝对精度后仍能保证"趋势正确"的唯一依据。
2. **精确极限**：静止小幅等于面元法；等速入水等于二维非线性解；静水力精确。这些是便宜的，也是防止系统性偏差的锚。
3. **阻尼与刚度的符号和量级**：控制器的稳定性取决于它们（例：5 节输运项给出的负纵摇阻尼贡献、12 节驼峰的双稳态）。要求"符号正确、量级在 2 倍内"，比要求"幅度 ±10%"更要紧。
4. **加速度统计的定义**（滤波、步长）。
5. **数值收敛**：任何表（三维线性、记忆）必须在自己的网格序列上收敛，否则不进模型——这是 5 节表当前不能用的原因，不是精度问题。

### 4.4 放低之后仍必须做的

- S1：5 节线性解收敛（否则低速航行一段没有可用的三维表）。
- 把 D1′ 装进船模（接口、记忆始终开、滤波、子步），用 A1–A6 的改写版验收。
- 登记并随机化四个经验项（浸湿后系数、通气、摩擦/飞溅、出水）。
- 真正困难的三项（滑行三维非线性参考、工作幅度非线性、6–14 节）标为"未知"，列入 `SIMULATOR_NEXT`，不阻塞控制侧的工作。
