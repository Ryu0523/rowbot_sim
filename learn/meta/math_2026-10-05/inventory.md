# Inventory of train/test differences and the evidence about each (2026-10-04)

Scope: every difference between (a) the pretraining episodes of the network that is evaluated today
(catalogue family D10a in the low-fidelity world, cache `studies/_cache/meta7`, driven by the data
autopilot) and (b) the targets it is tested on: the gz plant recorded with the hand controller
(`studies/onestep_gz.py`), the older targets C / Cb (cache meta2, copied into meta7), and the MPC closed
loop (`studies/final_eval.py`). For each difference: what the code does (file:line), every past
experiment that bears on it, what it measured, and what it does and does not establish.

Rules followed: equations and settings are taken from the code (file:line); where a docstring is quoted
it was checked against the implementation (noted where it was). "Not detected" is never written as
"absent". UNKNOWN marks what could not be determined, with the reason. Three small descriptive checks
were run for this inventory (section 5; each < 1 min, numpy only, no training).

- **G (gz test)**: `sim/planing_vessel_gz.py` PlaningVesselGZ (subclass of `sim/planing_vessel.py`

  (480 steps) = seeds 0–7 × legs 0, 1 (`studies/_cache/onestep_gz/streams_T120.pkl`). Default split:
  seeds 0–3 train/learn, seeds 4–7 held out (`onestep_gz.py:855-856`).

- **MPC-CL (closed loop)**: `studies/final_eval.py`, gz plant, same 16 mission seeds/legs, constrained
  MPPI with the learned model in the loop (`final_eval/meta7/report.txt`).
